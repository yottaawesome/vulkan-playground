## The Vulkan graphics pipeline.

1. Vertex/Index buffer. input.
2. Input assembler (fixed-function stage): collects the raw vertex data, and may includer an index buffer to avoid duplicating vertex data.
3. Vertex shader (programmable stage): runs for every pixel, and applies transformations from model space to screen space. Per-vertex data is passsed down the pipeline.
4. Tessellation (programmable stage): provides the ability to subdivide geometry on certain rules to improve mesh quality. See [here](https://docs.vulkan.org/spec/latest/chapters/tessellation.html).
5. Geometry shader (programmable stage): run on every primitive and can either discard or generate more primitives than came in. See [here](https://docs.vulkan.org/spec/latest/chapters/geometry_shader.html). Seldom used in production code due to poor performance, and its use cases are better handled by mesh shaders.
6. Rasterization (fixed-function stage): converts primitives into fragments, which are the pixel elements that will potentially fill the framebuffer. Frustum culling and depth testing is performed at this stage, and vertex shader interpolation also occurs at this stage.
7. Fragment shader (programmable stage): invoked for every fragment generated by rasterization. Determines which framebuffers the fragments are written to and their color and depth values.
8. Color blending (fixed-function stage): applies operations to mix different fragments that map to the same pixel in the framebuffer. Fragments may overwrite each other, be added up, or blended based on alpha values.
9. Framebuffers: output.

Fixed-functions staged have configurable parameters, but are fixed in their operations. Programmable stages allow your code to run directly on the GPU, allowing you to use the operations you need.

Unlike older APIs, the Vulkan pipeline is largely immutable, and you need to recreate the pepeline if you want to change shaders or bind different framebuffers. This means you'll have to create a number of different pipelines that represent all the different combinations of states you want to use in your rendering operations.
